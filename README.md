# Full-Stack Dev Task Tracker

A sleek, responsive Full-Stack Task Tracker designed for developers to manage their daily workflows. This project features a clean, dark-mode user interface that communicates seamlessly with a localized Python backend API.

## 🚀 Tech Stack

- **Frontend:** HTML5, CSS3 (Modern Dark Theme), JavaScript (Fetch API / Async-Await)
- **Backend:** Python, Flask, Flask-CORS
- **Architecture:** RESTful API
